Team of 2 building "Mandate" (working name; "Leash" is taken by another Monad project) at Monad Blitz Pune V3 on 10 Oct 2026.

Idea: give an AI agent a task, not your wallet. Each task gets an on-chain budget on Monad (allowed merchants by identity via a merchant registry, total cap, per-payment cap, expiry, auto-refund). Blocked attempts are recorded with a reason. Top-ups: the agent asks, only the owner can call increaseBudget. Plugs into agents via an MCP server. First customer: agent developers paying for APIs (x402); consumers later.
