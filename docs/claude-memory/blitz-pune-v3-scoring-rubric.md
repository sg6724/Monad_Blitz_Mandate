Monad Blitz Pune V3 is judged on a 400-point rubric by judges (no peer voting). Source: the event's Notion pack, "Judging Process & Rubrics Criteria" page.

- **Basic 100 (required to win):** public GitHub repo 25 · README with live public URL + contract address 25 · contracts deployed on Monad testnet 25 · publicly hosted (any host) 25. Say repo link, contract address, live URL and deployment out loud in the pitch.
- **Project working 100:** all announced functions work 25 · live on-chain tx during demo 25 · contract verified on explorer 25 · someone else can run it from the README 25.
- **Build in public 100:** X/LinkedIn post tagging @monad @monad_dev @geeky_kartikey 25 · demo video 30s+ posted 25 · creative product ad video posted 25 · 5K+ combined views by 5:45 PM IST 25.
- **Bonus 100:** Monad mainnet deploy 25 (organizers) · custom domain 15 (organizers) · pre-market fit up to 20 · revenue potential/strategy up to 20 · innovation/originality up to 20 (judges).

Timeline: hack start 11:30, lunch 1–2 PM, code freeze 5:30 PM, submission on Devnads portal by 5:45 PM (links, posts, view counts lock then), demos 6:00–8:30 PM at 3 min per team.

**Why:** the user asked to keep this rubric in mind for all decisions.
**How to apply:** never announce a feature that isn't working; plan time for social posts and videos; deploy to mainnet + custom domain for cheap bonus points; verify contracts. See [[mandate-project]] and [[blitz-rules-flexible]].
